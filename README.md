Smart Medicine Reminder

A C++ based medicine reminder and dose tracking system developed using Object-Oriented Programming (OOP) concepts.

Features

- Create and view user profiles
- Add and view medicines
- Store medicine details using file handling
- Track taken and missed doses
- Generate a medicine adherence report

Concepts Used

- Classes and Objects
- Inheritance
- Abstraction
- File Handling
- Exception Handling

Language

C++
